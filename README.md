# 📂 Universal File Handler

🕰️ ***Код был написан руками в далёком 2022 году..***

Универсальный обработчик табличных файлов форматов **CSV** и **XLSX** на Python.

Главная особенность проекта — автоматическое определение разделителя в CSV-файле. Обработчику не нужно заранее сообщать, чем разделены значения: запятой, точкой с запятой, табуляцией или другим символом.

## ✨ Возможности

- 📄 поиск всех `.csv`-файлов в указанной папке;
- 📊 чтение всех `.xlsx`-файлов;
- 🔎 автоматическое определение разделителя CSV;
- 🐼 преобразование содержимого файлов в `pandas.DataFrame`;
- 📦 объединение результатов в одном словаре;
- 💾 сохранение результата в файл `Result.pickle`.

## 🧠 Как определяется разделитель

Метод `find_delimiter()` анализирует содержимое CSV с помощью встроенного класса `csv.Sniffer`:

1. Читает образец данных из файла.
2. Находит предполагаемый разделитель.
3. Проверяет, встречается ли найденный символ в первых строках файла.
4. Возвращает разделитель для последующего чтения через `pandas.read_csv()`.

Благодаря этому один обработчик может работать с файлами разного вида без ручной настройки параметра `sep`.

```text
name,age,city
Alice,25,Moscow
```

```text
name;age;city
Alice;25;Moscow
```

Оба варианта будут обработаны автоматически. ✅

## ▶️ Использование

Импортируйте обработчик, создайте экземпляр класса и передайте путь к папке с файлами:

```python
from files_handlier import FileHandlier

handler = FileHandlier()
handler.main_handlier("./task_data")
```

После выполнения программы:

- `handler.res` содержит словарь вида `{имя_файла: DataFrame}`;
- в текущей рабочей папке появляется файл `Result.pickle`.

Пример чтения результата:

```python
import pickle

with open("Result.pickle", "rb") as file:
    data = pickle.load(file)

print(data.keys())
```

## ⚠️ Ограничения

- CSV-файл должен содержать как минимум две строки для текущей проверки разделителя.
- Автоматическое определение зависит от структуры входных данных.
- Входные файлы должны находиться непосредственно в указанной папке — вложенные каталоги не обходятся.
- Файлы `.xlsx` читаются с настройками `pandas` по умолчанию.

## 📌 Формат результата

Ключом словаря является имя исходного файла, а значением — соответствующий `DataFrame`:

```python
{
    "users.csv": pandas.DataFrame(...),
    "report.xlsx": pandas.DataFrame(...),
}
```
